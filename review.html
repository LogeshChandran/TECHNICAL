Your reviews

Mark charts with Good / Bad / Wrong type. Marks are saved on this device. To use them for tuning:

  1. Tap Export CSV.
  2. Upload the file to the private repo folder reviews/ (e.g. reviews/2026-11.csv).
  3. Run the workflow with mode tune. It writes tuning/report.md, suggested thresholds and (with enough labels) the learned ranker.

Aim for 150-300 marks across timeframes and patterns, including bad ones.
